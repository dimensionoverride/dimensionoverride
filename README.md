## About Us

Welcome to **Dimension Override**, an independent game development project focused on creating immersive, story-driven gaming experiences.

Our flagship project, **DIMENSION OVERRIDE**, combines psychological horror, dark fantasy, science fiction, and cooperative action.

## Our Game: DIMENSION OVERRIDE

**Genre:** Psychological Thriller / Sci-Fi / Dark Fantasy

**Game Engine:** Unity

**Platforms:** PC & Mobile

**Game Mode:** Multiplayer Co-op

### Core Gameplay — Reality Override

Experience a world where reality is never the same for everyone.

- Different players can perceive different versions of the same environment.
- Cooperate to uncover hidden pathways and solve reality-based puzzles.
- Explore mysterious environments and face psychological threats.
- Discover the truth behind fractured dimensions.

## Technologies

- **Game Engine:** Unity
- **Programming:** C#
- **3D Modeling:** Blender
- **Version Control:** Git & GitHub
- **Development:** Multiplayer Gameplay Systems
