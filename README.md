**Dimension Override** is a multiplayer psychological sci-fi thriller where players experience different versions of the same reality.

### 🌀 REALITY OVERRIDE SYSTEM

Our core gameplay mechanic introduces a unique cooperative experience.

- **Asymmetric Perception** — Different players perceive different dimensions.
- **Dynamic Reality** — Environments can shift during gameplay.
- **Cooperative Puzzles** — Challenges require communication and teamwork.
- **Alternate Pathways** — Hidden routes emerge across realities.
- **Psychological Tension** — Players must question what they see.
